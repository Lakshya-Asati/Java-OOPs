## 📖 Overview
This repository serves as a hands-on learning resource and reference guide for Object-Oriented Programming in Java. It covers fundamental principles—such as **Encapsulation, Abstraction, Inheritance, and Polymorphism**—alongside essential keywords, relationships, and modern Java features like **Records**.

---

## 🧱 Core Pillars of OOP

| Principle | Description | Key Java Keywords / Mechanisms |
| :--- | :--- | :--- |
| **Encapsulation** | Bundling data and methods while restricting direct variable access. | `private`, `getters/setters`, `record` |
| **Abstraction** | Hiding complex execution details and exposing only essential features. | `abstract`, `interface` |
| **Inheritance** | Enabling child classes to inherit attributes and methods from a parent class. | `extends`, `super` |
| **Polymorphism** | Allowing a single interface or method to take multiple forms. | `@Override`, Method Overloading |

---

## 💡 Key Java Concepts Covered
- **Access Modifiers:** `private`, `default`, `protected`, `public`
- **Control & Immutability Keywords:** `this`, `super`, `static`, `final`
- **Class Relationships:** Association, Aggregation, and Composition
- **Modern Java Features:** Immutability with Java Records (`record`)
